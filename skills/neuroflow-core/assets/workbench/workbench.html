Keyboard. Tab to a card. Enter or M opens “Move to”. Shift + ← / → moves it one column. ↑ ↓ ← → go between cards. U undoes the card's last waiting move. N adds a task. Esc closes a menu.

A move here is a request: Claude Code checks it against git and moves the task file when you run /neuroflow:tasks --apply-web.
